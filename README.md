# assignment-3-crudapi

A RESTful CRUD API for characters from the Assignment 2 website.

## Character API

All endpoints use the `/api/characters` base path. Character JSON contains
`characterId`, `name`, `description`, `type`, and `strategy`; `characterId` is
generated by the API when a character is created.

| Purpose | Method and path | Success status |
| --- | --- | --- |
| Get all characters | `GET /api/characters` | `200 OK` |
| Get one character | `GET /api/characters/{id}` | `200 OK` |
| Add a character | `POST /api/characters` | `201 Created` |
| Update a character | `PUT /api/characters/{id}` | `200 OK` |
| Delete a character | `DELETE /api/characters/{id}` | `204 No Content` |
| Filter by type | `GET /api/characters?type={type}` | `200 OK` |
| Search names (partial, case-insensitive) | `GET /api/characters?name={name}` | `200 OK` |

The `type` filter is case-insensitive and exact. The `type` and `name` query
parameters can also be combined.
